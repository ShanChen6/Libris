# Logo Libris

| Tệp | Dùng cho |
|---|---|
| `libris-logo.png` / `libris-logo-dark.png` | Logo đứng (biểu tượng + chữ), nền sáng / nền tối |
| `libris-logo-horizontal.png` / `libris-logo-horizontal-dark.png` | Logo ngang: đầu trang, slide |
| `libris-icon.png` / `libris-icon-dark.png` | Chỉ biểu tượng (cán cân + sách mở) |
| `libris-icon-512.png` | Biểu tượng vuông 512×512 |

Tất cả là PNG nền trong suốt, tách từ ảnh gốc nền trắng. Màu: xanh navy `#10213A`, điểm nhấn vàng
cam ở tâm. Bản `-dark` đổi phần navy sang `#F1F5F9` để dùng trên nền tối.

Trong `libris-web`: `public/libris-logo.png` (trang chủ), `public/libris-icon.png` (thanh đầu trang,
trang đăng nhập), `src/app/icon.png`, `src/app/apple-icon.png`, `src/app/favicon.ico` (biểu tượng tab).
